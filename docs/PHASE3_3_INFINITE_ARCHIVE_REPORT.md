# Phase 3.3 — Infinite Archive Overview

日期：2026-10-24。状态：已完成本地实现与下述验证，未 commit、push 或部署。

## 1. 改造范围与原结构

起点为 main 的 `e3a55be`。修改前首页通过 `ArchiveScene` 在 `FolderField` 双文件夹与 `MatrixField` 项目矩阵间切换。`bootstrap.ts` 负责输入、层级、动态加载与历史；`archive-model.ts` 保存项目/部分选择；`reader.ts` 继续从真实静态详情读取正文。

现在首页和二级共享一个 `MatrixField`，没有重新初始化 Astro，也没有重写科研内容、详情页、阅读器或部署流水线。用户已有未跟踪文件 `test` 未修改。T1 原仓库未访问或修改。内容集合、public/media 原素材、依赖与锁文件未修改。

## 2. 高空阵列与资源

- 复用 `CassetteKit` 的外壳、导轨、索引和材质；首页运行时不再导入 `FolderField`。历史文件及其回归测试保留。
- 全程读取同一个 manifest：4 个学术项目、2 个技术项目，各 4 份档案；装饰性重复实例不创建新的项目记录。
- 近景保持既有 9×36 / 移动 5×24 实例池和一个精细活动模型。
- `OverviewBackdrop` 使用三个共享几何 InstancedMesh 补足远景：本体、顶导轨、索引片。容量各 16,000，实际数量按视场覆盖计算。只在首次需要总览时创建；二级终点不渲染，离页统一释放。
- 对斜视地面投影额外覆盖；自动测试检查 1920×1080、2560×1080、320×844、390×844、844×390 的角点均在覆盖区内，且实例容量没有截断。

## 3. 相机、光影与最终审阅调整

先完成静态高空原型并在浏览器检查边界；修正近远景索引细节接缝后，再接入动画。根据后续反馈进一步降低镜头、增强光影和呼吸，采用以下最终参数：

| 参数 | 当前值 |
| --- | --- |
| 总览距离 | 180 |
| 总览观察方向 | normalize(-0.58, 0.69, 0.43)，俯角约 44° |
| 总览视场高度 | max(24, 28 / aspect) |
| 二级距离 / 基准目标 | 140 / (-1.091, -0.045, 0.481)，保留原有横竖屏规则 |
| 总览定向光位置 / 强度 | (-28,16,8) / 4.4 |
| 总览暖色聚光 | (-18,24,10) → (8,-2,0)，强度 2.8，柔边 0.85 |
| 总览曝光 | 1.06；二级恢复 0.94 |

初稿距离 210、视场高度 29；当前档案尺寸更大、可见密度更低。定向侧光与局部暖光提供面间明暗和空间层次。远景本体在桌面投射/接收阴影，深度着色器跟随呼吸；手机关闭阴影映射。

相机路径到达二级时，附加聚光强度归零、主光位置/强度与曝光恢复原值，二级既有模型和布局保持不变。

## 4. 分类标签、引线与双语

分类锚点对应其上次访问的真实项目/部分，首次访问使用首项目首部分。每帧从同一渲染相机投影到像素坐标；SVG 端点使用该结果，文本可作边界与窄屏避让。

引线由斜线接水平短线组成钝角，不再使用直角折线。未选中只显示“科研学术集 / 项目作品集”或英文名称。单击后出现局部波纹，并以 320ms 淡入上浮展开索引、项目数量、进入按钮。另一分类保持收起。数量来自 manifest。

按钮使用 aria-pressed / aria-expanded / aria-controls；未展开的信息使用 hidden，不进入键盘 Tab 顺序。中文菜单现为“联系我”，英文继续为 Contact。320px 中英文均实测没有横向溢出或标签重叠。

## 5. 呼吸、波纹和单份抬升

- 呼吸：9 秒 / 12 秒两项低频正弦，振幅 0.18 + 0.06，最大约模型高度的 6.5%。仅垂直位移，不旋转漂浮。近景 CPU 和远景顶点着色器使用一致的空间/时间公式；各零件统一回到档案原点采样，避免索引片与外壳脱离。
- 波纹：复用一对世界空间薄环，最长 0.9 秒，半径不超过 3.6；局部档案附加起伏不超过 0.075。重选覆盖当前波纹，不累积对象或任务。
- 确认：只抬升一个真实代表档案，目标高度 0.75；达到 0.66 后进入镜头下降。由实际渲染反馈触发，不用可能早于渲染完成的固定定时器。
- Reduced motion 禁用呼吸和波纹，直接到达目标状态。

## 6. 连续过渡与导航状态

HOME → `overview-lift` → `overview-travel` → PORTFOLIO_MATRIX → DOCUMENT_VIEWER。

下降路径为 2 秒五次平滑插值，辅以相机跟随弹簧短收尾；加上单份抬升，主过程约 3 秒。实际墙钟耗时受帧率及浏览器节流影响。返回使用 `overview-return`，从当前位置反向接续，不销毁/替换阵列。普通分类选择只在局部反馈，不平移整个档案世界。

`NavigationState` 增加每分类的 `projects` 记忆及 `overviewSelected`，保留每项目 rows 记忆。跨 Academic/Technical 的六项目循环、稳定 hash、真实 HTML 路由不变。单击选择、再次点击/双击/Enter/进入按钮确认；原有方向键、滚轮和阅读器保留。动画期间 busy 阻止重复进入；Esc、Contact、模式切换、历史恢复、离页可取消阶段，避免延迟回调重新打开已取消状态。

## 10. 性能、限制与人工验收

保留 DPR/像素预算、手机默认简洁模式、离屏/隐藏/Contact 暂停和统一 GPU 清理。总览多出远景实例和可选两环；无新模型、图片、字体请求或大型依赖。桌面一次采样：总览选中 49 calls / 353,122 triangles，二级稳定 41 calls / 170,418 triangles；这些是 renderer 计数，不是 FPS 或 GPU 基准。

尚未完成：真实手机触摸硬件、低端 GPU、Safari/Firefox、200% 浏览器缩放及长时间 GPU 内存采样。自动化浏览器存在帧调度差异，不声明稳定 60 FPS，也不把本地资源释放单测等同于长期显存分析。

建议人工验收：呼吸幅度与周期是否合适、暖光强弱、全程镜头舒适度，以及真机双击/两次轻触体验。性能较弱设备可直接使用简洁模式，内容不受影响。

本地预览：`npm run dev`，或 `npm run build` 后 `npm run preview`。本次验证使用 `http://127.0.0.1:4322/` 与 `/zh/` 的生产预览。线上网站尚未更新。
