# 手机端排版优化记录

## 2026-10-27 开屏与两段式阅读面板

用户已授权本轮提交与上线；实际部署结果以本次提交对应的 GitHub Actions 记录为准。

- 原因：bootstrap 接受 `?view=3d`，但内联 intro 仍按手机/粗指针跳过，导致首帧前出现静态文件夹。显式 3D 访问现在使用相同开屏遮罩，等待真正的 3D 首帧再淡出，通常总长约 3 秒；减少动态效果时仅保留静态首帧遮罩，立即退出。8.5 秒超时和简洁模式退出保留。不改变普通手机 URL 默认简洁模式的既有规则。
- 抽取沿用原有 900ms 先行阶段，进入阅读器后面板从屏幕下方滑入；收起位置为 max(250px, 52dvh)，展开位置为 max(132px, 24dvh)。桌面阅读区、相机与模型未修改。
- 手指上滑向下阅读时先展开，随后滑动正常滚动正文；正文顶部开始的新一次下拉收起。非顶部下拉仍滚动正文，一次手势只触发一次状态变化；水平操作及双指缩放不拦截。按钮提供等价操作。关闭后重置，切换章节保留面板状态；所有监听器由 AbortController 释放。
- 新增 `src/scene/reader-sheet.ts` 和 `tests/reader-sheet.test.mjs`；修改 intro.js、reader.ts、ArchiveTerminal.astro、mobile-archive.css 及 intro 测试。
- 验证：62 项测试通过；76 文件类型检查零错误/警告/提示；build、check:site（43 HTML / 1245 链接）及 format:check 通过。既有大 chunk 提示不变。
- 浏览器：本地正式构建，Edge 390×844，已验证收起/展开/收回按钮；展开面板顶部 202.55px（24%），无横向溢出；重新载入时 intro=loading 且 site-wrap=hidden。截图在 `qa/mobile-sheet/`。触屏手势使用单元事件测试，未宣称真实 iOS/Android 触屏验证。

## 2026-10-27 二级档案上方居中

根据最新反馈，手机竖屏二级的相机瞄准点沿屏幕竖直方向下移，使选中档案中心位于画面水平 50%、垂直约 32% 处；较短视口至少预留 196px，避开页头。使用稳定矩阵原点计算，不追逐实时呼吸位置。偏移通过原有 overviewGain / detail 插值接入，桌面、首页和阅读器最终相机不变。新增 320×568、390×844、430×932 下 A1/T1/T2 投影断言，60 项测试通过。旧截图仅展示上一轮排版，本轮浏览器连接不可用，最新构图仍需实际手机确认。

排版实施日期：2026-10-26；构图补充与发布授权日期：2026-10-27。用户已授权提交并推送本轮更新，Pages 结果以对应 GitHub Actions 记录为准。

## 修改内容

- 手机页头压缩为 72px，返回与模式切换保持同一行；保留触控目标和安全区。
- 首页在 650px 以下采用双列分类索引，横线随标签缩短。圆点仍使用真实 A1/T1 投影，波纹及镜头轨迹未修改。中英文分别使用触控操作提示。
- 二级在 767px 以下使用 Grid 自动高度排布摘要、部分导航和项目导航，替代固定 bottom 偏移。小高度页面允许滚动；长标题不与导航重叠。保留当前/总数、四份档案索引、相邻项名称及全部项目目录。
- 底部柔和浅色渐变提高文字可读性，不增加卡片背景或新模型。
- 阅读器占据更多竖向空间；手机端默认收起项目/部分切换按钮，通过“项目与部分导航”展开，正文优先。桌面端按钮继续常驻。新增监听器沿用 AbortSignal 清理。
- 未修改 Three.js 模型、相机参数、波纹、列顺序、动画、科研内容及静态总览内容。
